# 机械制图学习笔记

> 面向：大一新手 ｜ 软件：FreeCAD（Sketcher + Part Design + TechDraw）
> 主题：草图绘制 · 拉伸特征 · 打孔 · 尺寸标注

| 中文 | FreeCAD 名称 | 作用 |

## 1. 草图绘制

### 1.1 标准流程

1. 选基准面（XY / XZ / YZ），**不要**随手选实体表面
2. 先画大致形状，形状对了再改尺寸，不要边画边纠结数字
3. 加几何约束，把形状"定死"
4. 加尺寸约束，把大小"定死"
5. 确认求解器显示 **Fully constrained**（草图变绿）再退出

### 1.2 约束的先后顺序

- **先几何约束**：重合、水平、垂直、平行、垂直相交、相切、相等、对称
- **再尺寸约束**：长度、半径 / 直径、角度
- 能用对称约束的地方，不要用两个相同尺寸硬标

### 1.3 新手易错点

- **过约束**：同一特征标了两个互相冲突的尺寸 → 删掉多余的那个
- **欠约束**：鼠标拖动线条还能动，说明还有自由度没固定
- 尽量**不用"锁定"代替定位**，数量一多就乱；优先用原点 + 对称
- 草图尽量挂在基准面上，挂实体面容易在改尺寸后失效
- 尺寸不要标成一条链，全部从同一个基准引出

## 2. 拉伸特征

### 2.1 常用参数

| 参数 | 说明 |
| --- | --- |
| Length / Dimension | 给定拉伸长度，最常用 |
| Symmetric to plane | 关于草图面对称拉伸，对称件首选 |
| Two lengths | 两侧拉伸不同长度 |
| To last / Up to face | 拉伸到指定面，不用算长度 |
| Reversed | 方向反了就用它 |

### 2.2 布尔模式

- **新建实体**：第一个特征，生成独立实体
- **添加到已有实体**：做凸台、加强筋
- **从已有实体切除**：对应 Pocket
- 拉伸方向必须与草图面垂直，否则形状会被"斜着长"

### 2.3 顺序原则

- **先大后小**：先做主体外形，再开孔、开槽
- **圆角、倒角放最后**：提前做会让后续特征找不到边
- 对称零件把原点放在对称中心，后续装配和出图都省事

## 3. 打孔

### 3.1 三种做法

1. **草图圆 + Pocket**：最通用，异形孔、腰形孔都靠它
2. **Hole 特征**：Simple / Counterbore（沉头）/ Countersink（锥形沉头）/ Threaded（螺纹），尺寸自动按标准匹配
3. **圆柱体布尔减**：偶尔用来做定位台阶

### 3.2 定位与深度

- 孔的位置标**孔心到基准的距离**，不要孔心到孔心一链标到底
- 通孔用 **Through all**；盲孔要给深度，注意孔底会留钻尖
- 孔边到零件边缘建议 **≥ 1.5 倍孔径**，且不小于 3 mm，防止开裂

### 3.3 阵列孔

- 环形分布的孔用**环形阵列**，线性分布的用**线性阵列**
- 只标注**一个孔的位置** + 阵列的间距 / 角度和数量

### 3.4 螺栓过孔尺寸（ISO 273 中等配合）

| 螺纹 | 过孔直径 | 3D 打印建议 |
| --- | --- | --- |
| M3 | 3.4 mm | 3.6–3.7 mm |
| M4 | 4.5 mm | 4.7–4.8 mm |
| M5 | 5.5 mm | 5.7–5.8 mm |
| M6 | 6.6 mm | 6.8–6.9 mm |
| M8 | 9.0 mm | 9.2–9.3 mm |

- 沉头、沉孔的具体尺寸查标准（如内六角螺钉沉孔 GB/T 152.3），不要凭感觉画
- 螺纹孔在 FDM 打印件上精度差，优先用**热熔铜螺母**或直接过孔 + 螺母

## 4. 尺寸标注

### 4.1 两种尺寸要分清

- **草图尺寸**：驱动尺寸，改数字模型就变
- **工程图尺寸**：从动尺寸，只反映模型实际大小，改它不会改模型

### 4.2 尺寸三要素

尺寸界线（从轮廓引出）、尺寸线（带箭头）、尺寸数字。

### 4.3 标注基本原则

- 单位默认 **mm**，数字后面**不写单位**
- 数字朝上（竖直尺寸朝左），不能被任何图线穿过
- **小尺寸标在内，大尺寸标在外**，避免尺寸线相互交叉
- **尺寸链不封闭**：留一个自由尺寸由加工自然形成，否则误差无处分摊
- **统一基准**：以设计基准 / 加工基准标注，避免链式累积误差
- 配合面、安装孔中心距等重要尺寸必须**直接标出**
- 内形尺寸与外形尺寸分开标注，不要混在一起

### 4.4 常用符号

| 符号 | 含义 | 示例 |
| --- | --- | --- |
| Ø | 直径 | Ø10 |
| R | 半径 | R5 |
| □ | 正方形 | □20 |
| C1 | 1×45° 倒角 | C1 |
| M | 公制螺纹 | M3-6H |
| 2× | 相同要素数量 | 2×Ø3.4 通孔 |
| ⌴ | 沉孔 | ⌴Ø6.5 深 3.5 |

### 4.5 三视图口诀

- **长对正、高平齐、宽相等**
- 主视图选**最能反映零件形状特征**的方向
- 先画中心线、基准线，再画轮廓，最后标注尺寸

## 5. 建模自检清单

- [ ] 每个草图都完全约束（Fully constrained）
- [ ] 对称零件的草图关于原点对称
- [ ] 所有孔都有定位尺寸，阵列孔只标一组
- [ ] 没有过约束、没有重复标注
- [ ] 圆角、倒角在所有特征之后添加
- [ ] 导出 STEP 前用 Part → Check geometry 检查实体有效

## 6. 常见问题速查

| 现象 | 常见原因 | 处理 |
| --- | --- | --- |
| 草图提示欠约束 | 还有自由度没固定 | 补定位尺寸或对称约束 |
| 拉伸失败 | 草图不封闭、线条重叠或自交 | 用 Sketcher 找开口，删重复线 |
| 切除后模型没变化 | 方向反了或长度不够 | 点 Reversed 或改用 Through all |
| 改尺寸后模型"炸开" | 草图挂在实体面上 | 把草图改挂基准面 |
| 孔位置偏移 | 用了链式尺寸，误差累积 | 改为从统一基准标中心距 |
| 圆角加不上 | 圆角值大于相邻边长度 | 减小圆角值或调整特征顺序 |

## 7. 练习建议

1. 先临摹简单零件：垫片 → L 型支架 → 法兰盘
2. 每个零件都练一遍「建模 → 出三视图 → 标尺寸 → 导出 STEP」
3. 拿一个实物（角码、垫圈）用卡尺量尺寸，自己复原
4. 把做好的零件 3D 打印出来，用实物验证尺寸对不对
