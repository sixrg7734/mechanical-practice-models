# 机械建模练习 · Mechanical Practice Models

> 从机械制图到三维建模的学习记录｜SOLIDWORKS 练习件与 3D 打印件设计

## 关于这个仓库

这个仓库记录单纯我从零开始的机械建模学习过程，主要包含三块内容：

- **机械制图**：按制图规范练习的工程图（`drawings/`）
- **三维建模**：SOLIDWORKS 练习模型（`models/`）
- **3D 打印件设计**：可打印件的清单与工艺说明（`bom.md`）

这里不是成品展示，而是真实、持续更新的学习记录。每个练习件尽量做到「有图、有件、有说明」。

## 软件环境

| 工具 | 用途 | 版本 |
| --- | --- | --- |
| SOLIDWORKS | 三维建模、工程图 |SOLIDWORKS Design 2026|

> 模型源文件以 SOLIDWORKS 原生格式（`.SLDPRT` / `.SLDASM`）为主，同时导出通用的 `.STEP` / `.STL` 方便查看与 3D 打印。

## 目录结构

